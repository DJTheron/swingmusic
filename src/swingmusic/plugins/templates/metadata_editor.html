ℹ️ About

The Metadata Editor plugin lets you manually edit audio file tags (title, artist, album, genre, etc.), upload and embed album art, and use beets to auto-fetch and apply metadata from online databases.

Supported formats: MP3, FLAC, OGG Vorbis, Opus, M4A/MP4/AAC
